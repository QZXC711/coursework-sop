# 文本排版规范

把用户的个人排版规范落实为可编辑的文档格式，或据此检查现有文档。规范来自《【文本排版规范】.docx》；不是国家、学校或期刊通用标准。

## 使用方式与范围

- 排版或创建：采用下列规则；只排版时保留文字、数据、图片、公式、交叉引用及其原意。
- 检查：报告具体位置、当前格式、目标格式和问题；用户只要求检查时不改文件。
- 指定部分：只处理用户点名的部分，不借机重排整份文档。
- 用户当次要求和明确指定的模板优先于本技能；不同来源冲突时说明实际采用的要求。
- 原文件中的规范文字优先于示例段落的实际样式。需要溯源、解释歧义时读 [原始条文](references/source-rules.md)。不要照搬示例中的“文字文字”、样例数据、图片或未声明的页面设置。
- 处理 DOCX 时读 [Word 落地细则](references/word-implementation.md)。现有环境提供文档编辑与渲染工具时使用它们，但不要让通用视觉预设覆盖本规范。

## 执行流程

1. 识别原有层级、封面与正文起点、图表题注、来源、页眉页脚和分节。按语义识别段落，不只凭字号或是否加粗判断标题。
2. 建立对应的段落或字符样式，再处理冲突的直接格式。已有模板无冲突的部分保持原样。
3. 按下表落实排版；按条件处理数据来源、页眉页码和背景。没有实际来源不补造来源，没有背景素材不自行添加背景。
4. 检查实际格式，并在能渲染的环境逐页检查分页、字体、表格溢出、图片和题注位置。无法渲染时明确尚未完成视觉验证，不宣称版式完全合格。
5. 交付排版后的副本或用户要求的检查结果，简述修正内容和仍有影响的偏差。不覆盖源文件，除非用户已要求覆盖。

## 标题与正文

字号换算：三号 16 pt；四号 14 pt；小四 12 pt；五号 10.5 pt。“新罗马”统一使用字体名 `Times New Roman`。

下表段前、段后的单位均为**行**，不是磅；行距为“多倍行距 1.5 倍”。

| 角色 | 字体与字号 | 段前 | 段后 | 对齐及其他要求 |
| --- | --- | --- | --- | --- |
| 一级标题 | 黑体，三号 | 2 | 1 | 左对齐；每个一级标题段前分页 |
| 二级标题 | 黑体，四号 | 1 | 0.5 | 左对齐 |
| 三级标题 | 黑体，小四 | 0.5 | 0.5 | 左对齐；缩进两格 |
| 小标题 | 宋体，小四，加粗 | 0 | 0 | 独立成段时左对齐；缩进两格 |
| 正文 | 中文宋体，数字及英文 Times New Roman，小四 | 0 | 0 | 两端对齐 |

小标题允许两种形式，按现有文档或用户选择保留：

- 与正文同段：小标题后用句号或冒号收束，再接正文；仅小标题加粗，后续正文恢复正文格式，同段按正文两端对齐。
- 独立成段：小标题不加标点，下一段开始正文。

原规范未统一规定标题的英文字体、一级至三级标题是否额外加粗、正文首行缩进以及标题编号规则。保持已有设置；新建时按文档用途选择，不把示例 `1 / 1.1 / 1.1.1` 强加到所有文档。

“缩进两格”未区分首行缩进与整段左缩进；优先沿用原文档，新增时采用首行缩进两个中文字符作为实现约定。多行标题需要不同缩进效果时按用户要求调整，不把该约定称为原文硬性要求。

## 表格

- 表内文字：宋体，五号，单倍行距，段前段后 0 行；水平居中、垂直居中；表头行加粗。
- 较宽表格：根据窗口调整，使表格适合可用版心宽度。
- 较窄表格：根据内容调整后手动微调，一般可以适当加宽。不要强制所有小表占满版心。
- 对具有并列关系的数据行或列平均分布；描述列和数值列不因“平均分布”而一律等宽。
- 单元格高度目标为 0.7 cm；默认按最小行高实现，内容多时允许增高，防止裁切。原文件的样例也采用最小行高。
- 表后保留一个空段落：1.5 倍行距，段前段后 0 行。已有合适空段落时复用，避免每次排版再新增。
- 原文另有“文字对齐方式‘按照窗口调整’”的表述。结合前文将它理解为表格宽度适配，不覆盖表内文字的水平居中，也不取消窄表按内容调整的要求。
- 边框颜色、底纹、单元格边距未被明确规定：保留现有设置；新建时选择简洁、清晰的样式。

## 图片、题注和数据来源

图片所在段落：1.5 倍行距，段前 0.5 行、段后 0 行。保持图片比例；图片自身对齐方式和大小在规范中未明确规定。

题注共用格式：中文黑体，数字及英文 Times New Roman，五号，单倍行距，居中。

| 角色 | 位置 | 段前 | 段后 |
| --- | --- | --- | --- |
| 表格题注 | 表格上方 | 0 行 | 1 行 |
| 图片题注，无数据来源 | 图片下方 | 0 行 | 1 行 |
| 图片题注，有数据来源 | 图片下方、来源上方 | 0 行 | 0 行 |
| 表格数据来源 | 题注下方 | 0 行 | 0 行 |
| 图片数据来源 | 题注下方 | 0 行 | 1 行 |

- “表x”之后空两格再接题名；源示例使用两个普通空格，例如 `表1  题名`。保留已有“表”与数字之间的空格习惯。图题也可参照源示例 `图1  题名`，但原文只对表题明确规定了“两格”。
- 数据来源文字：宋体、五号、单倍行距；仅在需要且有真实来源时添加。原文未规定来源段落的水平对齐和西文字体，保持现有设置；新建时可与题注居中对齐，作为实现选择。
- 原规范要求来源“标在题注下方”：表题位于表上方时，顺序为表题、来源、表格；图的顺序为图片、图题、来源。用户指定其他顺序时从其要求。
- 将题注、来源和对应图表尽量保留在同页；长表合理跨页，不将整张长表强制挤入一页。

## 页眉、页码和通篇背景

- 页眉：居中，五号；中文宋体，数字及英文 Times New Roman；有封面时从封面后一页开始。保留现有页眉文字，或使用用户提供且能确定的文档信息，不编造单位名称。
- 页码：居中，五号 Times New Roman，从正文页开始显示，使用页码域。原规范未说明必须从数字 1 重新编号；保留已有编号逻辑，新建且无其他要求时可从 1 开始，并将其视为实现选择。
- 封面、目录、摘要或其他前置页是否存在，按文档实际需求决定，不为满足此规范凭空添加。正文起点不清且会改变页码范围时询问；继续完成不受影响的排版。
- 通篇背景仅在用户要求或原文件已有背景时处理：插入页眉，位于文字下方，固定于页面，覆盖整页。分节或首页不同的文档要检查各类页眉，包括封面页眉，避免有页面漏背景。
- 背景制作需考虑打印出血线；原文没有给出出血尺寸，不自行宣称满足某个印厂标准。需要精确印刷交付时以用户或印厂规格为准。

## 交付检查

- 标题字号、行距、段前段后、两格缩进及一级标题分页正确；没有重复分页造成的空白页。
- 中文和西文字体映射正确，未被主题字体或直接格式覆盖；缺失字体或替代字体已说明。
- 正文两端对齐；小标题两种形式的加粗范围正确。
- 表头加粗，单元格水平及垂直居中，窄表和宽表适配正确，0.7 cm 行高未裁切内容，表后只有所需的一个空行。
- 表题在上、图题在下；来源位置正确；有图片来源时题注段后改为 0 行，来源段后为 1 行。
- 页眉起始页与页码起始页分别核对；背景覆盖正确且不遮挡正文。
- 不把未规定的纸张大小、页边距、封面设计或示例中的实际格式报告为规范要求。
