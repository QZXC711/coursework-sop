# Word 落地细则

本文件是将规范落实到 Word / OOXML 的实现提示；技术选择不等同于原文新增要求。先读 `../SKILL.md` 的数值与条件。

## 编辑与保真

创建或修改 DOCX 时优先使用当前环境可用的文档工具。需要程序化处理时，可用 python-docx 配合有限的 OOXML 修改；保留现有关系、域、图片、公式、超链接和分节。不要为了设置字体重写整段 `paragraph.text`，这会丢失段内结构。

分别设置一级、二级、三级标题、正文、小标题、表内文字、表题、图题、来源、页眉及页码样式。内联小标题使用字符格式，不能让整段正文继承加粗。三级标题和小标题需要独立的缩进设置。

段落样式不一定覆盖已有直接格式。修改样式后检查段落和 run 的有效格式，只清理与本次排版规则冲突的属性，保留有意义的上下标、公式和局部强调。

## 字号与字体

| 中文字号 | pt | `w:sz` 半磅值 |
| --- | --- | --- |
| 三号 | 16 | 32 |
| 四号 | 14 | 28 |
| 小四 | 12 | 24 |
| 五号 | 10.5 | 21 |

在规定中西文字体的角色上，用 `w:rFonts` 的 `w:eastAsia` 设置宋体或黑体，用 `w:ascii` 与 `w:hAnsi` 设置 `Times New Roman`；不要只设置 `font.name` 而忽略中文字体。检查主题字体覆盖。对于原文只写宋体或黑体的角色，不擅自扩展“必须 Times New Roman”的范围。

检查字体可用性及渲染结果。没有宋体、黑体或 Times New Roman 时，不能把近似字体的输出称为完全符合；按环境能力处理并说明影响。

## 行距和段距

“1.5 倍”应使用多倍行距而非固定磅值：`w:spacing w:line="360" w:lineRule="auto"`。单倍为 `240`。

段前段后的“行”用 `w:beforeLines` / `w:afterLines` 表达，单位为百分之一行：

| 行数 | OOXML 值 |
| --- | --- |
| 0 | 0 |
| 0.5 | 50 |
| 1 | 100 |
| 2 | 200 |

不要把 0.5 行写成 0.5 pt，也不要只用 `space_before = Pt(...)` 声称精确复现按行段距。处理自动段距开关和旧的磅值段距冲突，并查看渲染后的实际效果。原文件中的文档网格不属于规范明文要求；若它干扰目标行距，明确调整相应段落网格行为并复核。

## 缩进与分页

“两格”使用字符单位而不是两个空格。采用首行缩进这一默认实现时设置 `w:ind w:firstLineChars="200"`，清除冲突的首行/悬挂缩进；若文档要求整段左缩进，则使用 `w:leftChars="200"`，不要两种同时叠加。保留有意的列表布局。

一级标题使用段前分页 `w:pageBreakBefore`。检查相邻手动分页、分节符，避免双重分页引入空页。可对标题、图表题注和相邻来源使用适当的 `keepNext`，但不要把整个长表或整章串成一个不可分页块。

## 表格与图表

- 0.7 cm 行高约为 397 twips，设置 `w:trHeight w:val="397" w:hRule="atLeast"`。python-docx 对应最小行高规则；不默认使用 `exact`。
- 单元格垂直居中使用 `w:vAlign w:val="center"`，其内所有段落水平居中、段前段后 0、单倍行距，消除正文缩进残留。
- 宽表按版心宽度设置表宽、网格及必要的单元格宽度，不把 `autofit = True` 视为“根据窗口调整”已经完成。窄表按内容和实际渲染调整。
- 并列数据行列可平均分配；多行文本导致的高度增长优先保证可读性。
- 复用已有表后空段落，设置 1.5 倍行距和 0 行段距。空段落不能误留标题大纲级别或段前分页。
- 题注保留或创建合适的序号域及交叉引用，不能仅为了外观把已有域替换成普通文字。题名间的两个空格需要保留空白字符。
- 图片默认保留原对象和纵横比；修改图片段落的间距，不拉伸图片去适配版心。

## 页眉页脚与背景

分别确定“封面结束”和“正文开始”两个边界；它们通常不是同一页。利用分节、首页不同和链接到前节设置，使封面隐藏页眉文字、前置页隐藏正文页码、正文显示页码。不要在所有节上同时开启“首页不同”，导致每章首页缺少应有页码。

页码使用 `PAGE` 域并检查缓存或渲染显示。没有明示重启要求时保留现有起始数字。

背景需用页眉中的浮动图片，置于文字后方，相对于页面绝对定位并锁定页面位置；不能用正文中的普通嵌入图片冒充背景。不同节、奇偶页和首页页眉都要核对。封面隐藏页眉文字不等于必须隐藏通篇背景。

## 验证

结构检查应检查实际生效属性、分节、域和表格属性；视觉检查应覆盖每页、封面后第一页、正文第一页及跨页图表。渲染能力受限时报告未验证项，保留可编辑 DOCX；不要用截图替代可编辑内容后宣称 Word 排版完成。
