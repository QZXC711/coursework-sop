# coursework-sop｜课设与大作业 SOP

这是我在大学期间，为节省课程设计和大作业时间，逐步整理的一套个人 SOP

排版、画图、准备论文阅读汇报这些工作经常重复做，也容易在细节上花掉很多时间，所以我把常用规范整理成了可以复用的 AI Skills。希望把更多时间留给作业中的创作性内容

目前主要面向个人经管类课程作业，后续会根据实际需要补充流程、模板和工具

## 目前包含什么

| Skill | 用途 | 文件夹 |
| --- | --- | --- |
| 文本排版规范 | 统一 Word 文档中的标题、正文、表格、图片题注、页眉和页码 | [text-layout](./text-layout/) |
| 制图标准 | 按统一规范规划和绘制机制图、逻辑图、理论图及结构示意图 | [drawing-standard](./drawing-standard/) |
| 论文阅读汇报 | 从大纲到逐页设计，安排原文图表、公式、来源与讲稿，支持图表简化重绘 | [paper-reading-presentation](./paper-reading-presentation/) |

### 文本排版规范

根据个人常用的文本排版要求，整理文档的字体、字号、行距、段落间距、标题层级，以及图表和页眉页码格式

支持按规范排版，也可以仅检查现有文档的格式问题。只进行排版时，保留原有内容和原意

调用示例：

```text
$text-layout 请按我的文本排版规范整理这份 Word 文档，保留原有内容。
```

```text
$text-layout 请检查这份文档有哪些不符合排版规范的地方，先不要修改文件。
```

### 制图标准

包含常用图形、连线、字体、字号和三组色卡，并采用“先确认思路，再开始绘图”的流程：

1. 先用文字说明核心内容、主要模块、关系和布局
2. 同轮确认色卡编号，以及是否需要【图片大标题】
3. 用户确认后再开始生成
4. 检查图片效果与文件可编辑性，再交付结果

默认设置：

| 项目 | 默认值 |
| --- | --- |
| 色卡 | 1 号色卡 |
| 图片大标题 | 不设置 |
| 图片输出 | PNG，600 dpi |
| 可编辑文件 | SVG，保留可分别编辑的文字、形状和连线 |

如需其他格式、尺寸或分辨率，可以在确认绘图方案时提出。

调用示例：

```text
$drawing-standard 请根据以下内容画一张逻辑图，先给出文字思路供我确认。
```

```text
$drawing-standard 请规划一张机制图，使用2号色卡，不需要大标题，先不要生成。
```

### 论文阅读汇报

用于课堂展示、论文分享和组会汇报，按“先大纲、再逐页”的方式辅助制作 PPT。适合自己制作页面、希望获得具体指导的场景，也支持按要求提取原图、生成新图或制作演示文件。

主要流程：

1. **核对原文**：记录论点、数据、图表面板、公式编号和页码，确认样本与研究设定。
2. **设计大纲**：规划页数、每页要回答的问题、前后逻辑和时间分配。
3. **逐页指导**：提供可直接使用的标题、短文案与布局，明确哪张原图、哪个面板、哪个公式放在哪里；也可检查已经制作的页面截图。
4. **整理图表与来源**：提取原图，或根据可核实的数据把复杂图表改绘成适合展示的图；规范填写“来源 / Source”，区分原图、自制示意图和数据重绘。
5. **编写与汇总讲稿**：按页面顺序整理口头讲稿、转场和结束语，修改某页后同步更新汇总稿和时间预算。
6. **总结与评价**：先说明论文结论，再陈述个人启发；区分作者做过的检验与自己提出的进一步研究方向。

默认设置：

| 项目 | 默认方式 |
| --- | --- |
| PPT语言 | 中文，保留必要的英文术语与原图文字 |
| 讲稿语言 | 中文，可与PPT语言分别指定 |
| 协作节奏 | 先设计大纲，再逐页推进 |
| 表达风格 | 简洁、准确、适合课堂口头讲解 |
| 图表重绘 | 根据原文可核实的数据制作，保留来源、单位与比较条件 |

例如，指定“PPT用英文”时，讲稿仍默认中文；需要两者都使用英文时可分别说明。

调用示例：

```text
$paper-reading-presentation 帮我准备这篇论文的12分钟课堂汇报，先给出大纲，说明每页放原文的哪张图、哪个公式。
```

```text
$paper-reading-presentation 接下来做第5页。PPT用英文、讲稿用中文，请给出布局、可复制文案、Source和约1分钟的讲稿。
```

```text
$paper-reading-presentation 原文这张图太复杂，请根据对应表格数据简化重绘，保留关键比较和来源，并给我可插入PPT的图片。
```

```text
$paper-reading-presentation 把当前各页的中文讲稿汇总成一份。最后先说三点论文结论，再说对应的三点启发。
```

工作细则见 [SKILL.md](./paper-reading-presentation/SKILL.md)，包括[逐页指导](./paper-reading-presentation/references/slide-guidance.md)、[图表与来源](./paper-reading-presentation/references/figures-and-sources.md)和[讲稿整理](./paper-reading-presentation/references/speaker-notes.md)。

## 如何使用

这些 Skills 面向 Codex 使用。

1. 下载本仓库并解压。
2. 将需要的技能文件夹放入本地技能目录，默认位置为 `~/.codex/skills/`。如果设置了 `CODEX_HOME`，则放入该目录下的 `skills/`。
3. 保留技能文件夹中的全部文件，不要只复制 `SKILL.md`。
4. 在支持技能调用的对话中，使用上述示例调用，并提供需要处理的文档、绘图内容或论文材料。准备汇报时，补充课程要求、展示时长和已有页面会更方便。

也可以直接阅读各技能的 `SKILL.md`，将其中的规范作为手动排版、绘图和准备论文汇报的参考。

## 使用说明

- 这里整理的是个人习惯，不是统一的学校、期刊或国家标准。老师、课程或投稿方有明确要求时，以其要求为准
- Skills 提供操作规范，实际生成和编辑文件仍需要运行环境具备相应工具及字体
- 制图标准技能默认输出 **PNG 600 dpi + 可编辑 SVG**，以当前技能文件中的设置为准
- 论文阅读汇报中的图表与数值应回到原文核对，个人评价和配置启发需明确标注
- AI 可以帮助处理重复工作，最终内容、逻辑和格式仍需要自己检查

这个仓库会随着我的课程学习和实际使用持续更新！
