# coursework-sop｜课设与大作业 SOP

这是我在大学期间，为节省课程设计和大作业时间，逐步整理的一套个人 SOP。

排版、画图这些工作经常重复做，也容易在细节上花掉很多时间，所以我把常用规范整理成了可以复用的 AI Skills。希望把更多时间留给作业内容本身。

目前主要面向个人经管类课程作业，后续会根据实际需要补充流程、模板和工具。

## 目前包含什么

| Skill | 用途 | 文件夹 |
| --- | --- | --- |
| 文本排版规范 | 统一 Word 文档中的标题、正文、表格、图片题注、页眉和页码 | [text-layout](./text-layout/) |
| 制图标准 | 按统一规范规划和绘制机制图、逻辑图、理论图及结构示意图 | [drawing-standard](./drawing-standard/) |

### 文本排版规范

根据个人常用的文本排版要求，整理文档的字体、字号、行距、段落间距、标题层级，以及图表和页眉页码格式。

支持按规范排版，也可以仅检查现有文档的格式问题。只进行排版时，保留原有内容和原意。

调用示例：

```text
$text-layout 请按我的文本排版规范整理这份 Word 文档，保留原有内容。
```

```text
$text-layout 请检查这份文档有哪些不符合排版规范的地方，先不要修改文件。
```

### 制图标准

包含常用图形、连线、字体、字号和三组色卡，并采用“先确认思路，再开始绘图”的流程：

1. 先用文字说明核心内容、主要模块、关系和布局。
2. 同轮确认色卡编号，以及是否需要图片大标题。
3. 用户确认后再开始生成。
4. 检查图片效果与文件可编辑性，再交付结果。

默认设置：

| 项目 | 默认值 |
| --- | --- |
| 色卡 | 1 号色卡 |
| 图片大标题 | 不设置 |
| 图片输出 | PNG，600 dpi |
| 可编辑文件 | SVG，保留可分别编辑的文字、形状和连线 |

如需其他格式、尺寸或分辨率，可以在确认绘图方案时提出。

调用示例：

```text
$drawing-standard 请根据以下内容画一张逻辑图，先给出文字思路供我确认。
```

```text
$drawing-standard 请规划一张机制图，使用2号色卡，不需要大标题，先不要生成。
```

## 如何使用

这些 Skills 面向 Codex 使用。

1. 下载本仓库并解压。
2. 将需要的技能文件夹放入本地技能目录，默认位置为 `~/.codex/skills/`。如果设置了 `CODEX_HOME`，则放入该目录下的 `skills/`。
3. 保留技能文件夹中的全部文件，不要只复制 `SKILL.md`。
4. 在支持技能调用的对话中，使用上述示例调用，并提供需要处理的文档或绘图内容。

也可以直接阅读各技能的 `SKILL.md`，将其中的规范作为手动排版和绘图的参考。

## 使用说明

- 这里整理的是个人习惯，不是统一的学校、期刊或国家标准。老师、课程或投稿方有明确要求时，以其要求为准。
- Skills 提供操作规范，实际生成和编辑文件仍需要运行环境具备相应工具及字体。
- 制图参考图片中的旧输出要求为 1440 dpi；本技能已调整为默认 **PNG 600 dpi + 可编辑 SVG**。
- AI 可以帮助处理重复工作，最终内容、逻辑和格式仍需要自己检查。

这个仓库会随着我的课程学习和实际使用持续更新。
