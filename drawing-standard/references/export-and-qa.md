# 输出与验证

本文件规定如何落实用户要求的 PNG 600 dpi 和可编辑 SVG；绘图前的用户确认仍由 `../SKILL.md` 控制。

## 同一矢量源，两种输出

优先在矢量场景中绘制节点、组框、文字和连线，再从同一场景生成 SVG 与 PNG。可选原生 SVG、支持矢量导出的绘图库或可编辑绘图应用，按任务与环境选择。不要求用户为了本规范预先选软件。

SVG 保留独立对象：`<g>` 用于分组，`<text>` / `<tspan>` 用于文字，`<rect>` / `<circle>` / `<ellipse>` / `<polygon>` / `<path>` 等用于形状，线条和箭头可用路径及 marker。写入可辨认的对象 ID 有利于后续编辑。保留完整 viewBox 和必要命名空间。

文字使用宋体与 Times New Roman 的对应字体或分别指定的文字片段；不要依赖某台机器上的静默字体回退。SVG 中保留字体名不等于字体已嵌入，跨设备仍需要相应字体。未经用户要求不打包受授权限制的字体文件。

如用 matplotlib，检查最终 SVG 文本是否仍为文本（常见做法是 `svg.fonttype = 'none'`），并检查中文实际字体；字体转为路径只能保证轮廓，无法继续像普通文本那样修改。无论使用什么工具，都以导出的实际文件为准。

## 物理尺寸、像素和 dpi

没有用户指定尺寸时，根据确认的布局选择合理物理宽高并在文字方案中说明；需要适配单栏、双栏或幻灯片时以实际版心为准。不要为凑某个任意像素宽度偷偷缩小 20 pt 的正文。

PNG 像素尺寸按以下公式确定：

`像素 = 毫米 ÷ 25.4 × 600`，四舍五入到整数。

例如 180 × 120 mm 对应约 4252 × 2835 px；这是计算示例，不是强制画布大小。600 dpi 导出时写入 PNG 分辨率元数据。PNG 使用每米像素存储分辨率，回读约 599.9988 dpi 等微小舍入偏差是正常的。

PNG 的高分辨率应来自矢量源或足够清晰的原始素材重新渲染；给低分辨率位图补写 dpi 标签、简单放大像素或换文件扩展名都不满足此要求。

SVG 是矢量格式，本身没有“600 dpi”的固有分辨率。为其设置合理的 `width` / `height` 和 `viewBox`，让文字大小、线宽与 PNG 对应。SVG 内的局部位图素材另行检查有效分辨率。

使用 pt 线宽时保持单位一致：1 pt = 1/72 英寸；在 96 CSS px / 英寸的 SVG 坐标体系里，1 pt = 4/3 用户单位。最稳妥的是显式带 `pt` 单位并核对变换影响，不能把 2 pt 直接当成任意缩放下的 2 px。

## 验证项目

### PNG

- 文件可打开，宽高与选定物理尺寸及 600 dpi 对应；分辨率元数据存在且约为 600 dpi。
- 在预期使用尺寸下字号可读，图边缘没有裁切；透明或白底按用户要求和实际用途选择，默认沿用参考图白底。
- 不以 600 dpi 元数据掩盖低分辨率源素材；必要时说明照片等局部素材的清晰度限制。

### SVG

- XML 合法，尺寸和 viewBox 完整；无依赖临时路径的外链图片或丢失素材。
- 主体不是单个整图 `<image>`；存在独立的文字、形状与连线对象。
- 有文字内容的图保留文本元素，字形可显示；不要为了通过数量检查而在位图上叠放无关或透明文本。
- 数学符号或个别图标可能需要路径，但普通标题、节点标签与箭头文字保持文本。明确说明无法作为文本编辑的例外。
- 箭头方向、虚线、圆端点、双圆和前后层级渲染正确；背景和边框没有遮挡内容。
- 用可用 SVG 渲染器查看导出文件，并与 PNG 比较布局、颜色、线宽、字体和换行。

### 用户确认一致性

核对已确认的核心表达、节点清单、关系方向、色卡编号、大标题开关及文字、格式与尺寸。不得以“视觉优化”替换已确认的事实关系或把推测画成确定因果。

## 交付

默认仅交付最终 PNG 和 SVG，使用同一文件名主干。若用户要求其他格式，按已确认的增加或替换关系交付。检查图片及可编辑性的能力不足时说明具体未验证项，不虚构验证结果。
